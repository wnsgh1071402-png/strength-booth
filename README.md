# 빛나는 나 발견하기

청소년 웰니스 부스용 강점검사 웹앱. 참여자는 **자기 폰**으로 검사하고, 상담자는 **태블릿**에서 결과를 실시간으로 받아 함께 보며 상담합니다.

- 이론 근거: VIA 성격강점 24개 (긍정심리학, 셀리그만·피터슨)
- 문항은 전부 오리지널 창작 — VIA의 분류 체계만 참고했고, CST-A·Clifton 등 상업 검사 문항은 사용하지 않았습니다.
- **개인정보를 수집하지 않습니다.** 이름·나이·학교를 묻지 않고, 참여자 식별은 당일용 4자리 임시 번호만 씁니다.

## 부스 운영 흐름

```
[청소년 폰]                                    [상담자 태블릿]
QR 스캔 → index.html                          staff.html (북마크 + PIN)
영역 선택 → 24문항 → 결과 TOP 3                      ↑ 실시간 자동 갱신
        ↓ 제출                                       │
   4자리 번호 표시  ────────────────────────────────┘
   "선생님, 4821이요"                        → 그 번호 탭 → 큰 화면 결과
                                              + 강점별 상담 대화 포인트
                                              + 오늘 집계
```

세션은 **날짜로 자동 분리**됩니다(`YYYY-MM-DD`). QR 주소는 영구 고정이라 매일 다시 인쇄할 필요가 없습니다.

## 검사 구성

VIA 24개 강점을 4개 영역 × 6개로 중복·누락 없이 배분했습니다. 참여자는 **한 영역만** 선택해 24문항(강점당 4문항, 5점 척도)을 응답합니다.

| 영역 | 강점 6개 |
|------|----------|
| 🤝 관계에서의 나 | 다정함 · 눈치·소통 · 함께하는 힘 · 이끄는 힘 · 공정함 · 유쾌함 |
| 🌱 배움과 성장에서의 나 | 궁금한 게 많은 · 배우는 재미 · 새로 만드는 힘 · 따져보는 힘 · 깊이 보는 눈 · 끝까지 가는 힘 |
| 🔥 도전 앞에서의 나 | 용기 · 에너지 · 잘될 거란 믿음 · 나를 다잡는 힘 · 솔직함 · 신중함 |
| ✨ 나를 표현하는 나 | 마음을 주는 힘 · 털어내는 힘 · 겸손함 · 아름다움을 아는 눈 · 고마움을 아는 마음 · 나만의 가치관 |

채점: 강점별 4문항 합산(4~20점) → 정렬 → TOP 3. 동점은 정의된 순서를 우선하고, 3위가 동점이면 함께 표시합니다.

## 실시간 동기화 설정 (Firebase)

**설정 전에도 앱은 동작합니다.** `assets/firebase-config.js`가 비어 있으면 자동으로 **로컬 모드**로 떨어져, 결과가 그 기기 안에만 저장됩니다. 부스 와이파이가 끊겨도 검사 자체는 계속 굴러갑니다.

폰 → 태블릿 실시간 전달을 켜려면:

1. [console.firebase.google.com](https://console.firebase.google.com) 에서 프로젝트 생성 (Analytics 불필요)
2. 웹 앱(`</>`) 추가 → `firebaseConfig` 객체 복사
3. `assets/firebase-config.js`의 빈 문자열에 붙여넣기
4. Firestore Database 생성 — 프로덕션 모드, 위치 `asia-northeast3`
5. 규칙 탭에 아래를 붙여넣고 게시

```js
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /booths/{booth}/results/{doc} {
      allow read: if true;
      allow create: if request.resource.data.areaId is string
                    && request.resource.data.scores is map;
      allow update, delete: if false;
    }
  }
}
```

Firebase 웹 API 키는 공개돼도 되는 값입니다. 실제 보안은 위 규칙이 담당합니다. 누구나 쓰기가 가능한 구조라 장난 데이터가 들어올 수는 있지만, `update`/`delete`를 막아 기존 결과가 훼손되지는 않습니다.

## 상담자 화면 PIN

`assets/firebase-config.js` 맨 아래 `STAFF_PIN` 값을 바꾸세요. 기본값은 `2026`입니다.

> ⚠️ 이 PIN은 **참여자가 실수로 들어오는 걸 막는 용도**이지 보안 장치가 아닙니다. 저장소가 공개돼 있어 소스에서 PIN을 읽을 수 있고, Firestore 규칙도 읽기를 열어두고 있어 주소를 아는 사람은 결과를 조회할 수 있습니다. 대신 저장되는 데이터에 **개인을 특정할 정보가 전혀 없습니다** — 당일용 4자리 번호, 선택한 영역, 강점 점수뿐입니다. 이름이나 연락처를 추가로 수집하는 개조는 하지 마세요.

## 로컬에서 확인하기

ES 모듈을 쓰기 때문에 파일을 더블클릭하면 열리지 않습니다. 정적 서버가 필요합니다.

```bash
python -m http.server 8765
# → http://127.0.0.1:8765/index.html
```

## 문항·문구 수정하기

모든 콘텐츠는 [`assets/data.js`](assets/data.js) 한 곳에 있습니다. 수정 후 정합성 검사를 돌리세요.

```bash
node verify.mjs
```

영역 4개 / 강점 24개 / 문항 96개 / 상담 가이드 24세트가 맞는지, 문구 중복은 없는지, 채점 경계값과 동점 처리가 맞는지 확인합니다.

> ⚠️ 문항을 추가·삭제하면 출제 순서가 바뀝니다. 순서는 영역 id를 시드로 한 고정 셔플이라 **같은 데이터면 항상 같은 순서**지만, 데이터가 바뀌면 이전 응답 배열로는 채점을 재현할 수 없습니다. 부스 운영 중에는 수정하지 마세요.

## 안내

진단 도구가 아니라 **발견과 응원**을 위한 부스 활동입니다. 결과는 우열이 아니라 "지금 너에게서 잘 보이는 것"으로 다뤄 주세요.
